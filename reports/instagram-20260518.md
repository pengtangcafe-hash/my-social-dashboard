## 4. Audience Insights

- **Link Clicks = 0 ตลอด 28 วัน** ทั้งที่มี Profile Visits 333 ครั้ง — คนเข้ามา profile แล้ว แต่ไม่มี link ที่ชัดเจนให้คลิก หรือ link ใน bio ไม่ดึงดูดพอ
- **ER สูงสุดในวันที่ reach ต่ำที่สุด (27 เม.ย. = 14.29%)** — core followers ที่ติดตามจริงๆ มี engagement สูงมาก แต่ algorithm ไม่ boost เนื้อหานั้นออกไป
- **Impressions (10,477) < Reach (15,307)** — ข้อมูลผิดปกติเล็กน้อย อาจเกิดจาก Stories ที่นับ reach แต่ไม่นับ impressions หรือข้อมูล export ไม่ครบ
- **Profile Visits 333 ครั้ง** เฉลี่ย 11.9/วัน — มีคนมาดู profile อยู่ แต่ไม่มี link ที่ดึงไป conversion ต่อ

## 5. Recommendations

1. **แก้ Instagram Link-in-Bio ด่วนที่สุด** — เปลี่ยนเป็น Linktree หรือหน้า landing page ที่มีปุ่มนัดหมาย/LINE OA ชัดเจน และใส่ "คลิก link ใน bio เพื่อนัดหมาย" ในทุก caption เพราะ 28 วัน 0 คลิก = เสียโอกาส conversion ทั้งหมด
2. **ทำซ้ำ content แบบ 28 เม.ย.** — วันนั้น ER = 4.1% สูงกว่าค่าเฉลี่ย 2.4 เท่า ดูว่าโพสต์อะไร (before-after, tips, case study?) แล้วทำเป็น series
3. **ทดสอบ posting time ช่วง 8–10 พ.ค.** — reach พุ่งขึ้นมาก อาจเกิดจากเวลาโพสต์ที่เหมาะกับ audience หรือ hashtag ที่ใช้ ให้ post content ใหม่ในช่วงเวลาเดียวกันเพื่อ validate
