## วัตถุประสงค์ของ Intelligence Module

ระบบ `/intel` ในโปรเจกต์นี้มีเป้าหมาย 3 ด้าน:
1. **ติดตามคู่แข่ง** — Social media activity, content strategy, pricing, hashtags
2. **หา Market Gaps** — สิ่งที่คู่แข่งยังไม่ทำ เพื่อโอกาสทางการตลาด
3. **แจ้งเตือน Trends** — Hashtag trends, Dental industry news, equipment innovation

---

## Framework การวิเคราะห์คู่แข่ง (5 มิติหลัก)

### มิติ 1: Social Media Presence
- แพลตฟอร์มที่ใช้ (Facebook / TikTok / Instagram / LINE OA / YouTube)
- แพลตฟอร์มไหน Active มากที่สุด / ทิ้งร้าง
- จำนวน Followers/Likes, Engagement Rate, ความถี่โพส
- โพสไหนมี Engagement สูงสุด
- ทิศทาง Comment (บวก/ลบ/ไม่มี)

### มิติ 2: Content Strategy
- รูปแบบ: วิดีโอ Before/After, Reels, รูปภาพ+caption, Live, Stories
- Theme: โปรโมชั่น, ผลงานจริง, Educational, บรรยากาศคลินิก, ทีมหมอ, Seasonal
- โทนการสื่อสาร: ทางการ vs กันเอง, ใช้ภาษาอีสานไหม, มี Presenter/Influencer
- Hashtags ที่ใช้บ่อย

### มิติ 3: Pricing & Promotions
- ราคาที่ประกาศในโซเชียล (จัดฟัน, รากเทียม, วีเนียร์, ฟอกสี ฯลฯ)
- โปรโมชั่น (ผ่อน 0%, แพ็กเกจ, โปรนักศึกษา)
- ราคาเทียบกับตลาด
- มีบัตรสมาชิก / Loyalty Program

### มิติ 4: Services & Positioning
- บริการหลักที่เน้น
- Tagline / จุดขาย (ราคา, หมอเชี่ยวชาญ, เทคโนโลยี, สะดวก)
- กลุ่มเป้าหมายที่ชัด (วัยรุ่น, ผู้ใหญ่, ผู้สูงอายุ)
- เวลาเปิด-ปิด / วันหยุด

### มิติ 5: Reputation & Reviews
- Google Maps (ดาว, จำนวนรีวิว, คอมเม้น)
- รีวิวใน Facebook / TikTok / Wongnai
- วิธีตอบรีวิวแง่ลบ
- ช่องทาง Booking (Walk-in / LINE / Facebook / App)

## Intelligence Dashboard — สิ่งที่ต้องสร้าง

### หน้า `/intel` ที่ต้องการ (UI Requirements)

1. **Competitor Cards** — การ์ดแต่ละคู่แข่ง แสดง platform, activity level, top hashtags, strengths/weaknesses
2. **Hashtag Heatmap** — hashtags ที่ควรใช้ แบ่งตาม Local / National / Trend
3. **Pricing Comparison Table** — เปรียบเทียบราคาบริการแต่ละคลินิก
4. **Gap Analysis Panel** — ช่องว่างที่คู่แข่งยังไม่ทำ
5. **Market Trends Feed** — ข่าว/เทรนด์ล่าสุด (Longevity Dental, Dental Tourism ฯลฯ)
6. **Events Calendar** — งานประชุมวิชาการทันตกรรม 2026

### Data Source
- `reports/intel-*.md` — base data ที่มีอยู่แล้ว
- `/intel` command — trigger ค้นหาข้อมูลใหม่
- Intel-agent JSON output — structure สำหรับ render cards

## โครงสร้างที่มีอยู่แล้วใน .claude/

```
.claude/
  commands/
    intel.md      ← /intel [topic] [city] command
    analyze.md    ← /analyze FILE
    compare.md    ← /compare
  agents/
    intel-agent.md   ← agent ค้นหา+ส่ง JSON structure
    data-agent.md
```

Intel-agent ส่งคืน JSON array ที่มี fields:
`id`, `category`, `title`, `summary`, `source_url`, `tags`, `relevance`,
`detail`, `pricing` (ราคาแต่ละบริการ), `strengths`, `promotions`, `social_trend`
